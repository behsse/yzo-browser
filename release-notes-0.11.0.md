## Yzo 0.11.0

Updates you can see coming: Yzo now shows when a new version is out, how far its download is, and lets you restart on it in one click.

### Highlights

- **Update indicator next to the Yzo logo.** While a new version downloads, its arrow sits in a ring that fills in violet from 0 to 100 %. Once it is done, the ring becomes a full violet circle with a check: click it to restart on the new version. Otherwise it installs when you quit Yzo.
- **Update automatically, or not.** Settings > About has an "Update automatically" switch, on by default. Turned off, Yzo still checks for new versions and shows one as the download arrow with a violet dot; click it to download.
- **Settings > About.** Shows where the update stands (checking, a progress bar while it downloads, ready, failed) with the matching button: check for updates, download, or restart.
- **Never miss one.** Toasts tell when a new version is found and when it is ready, the Yzo menu offers "Restart to update", and Yzo checks every 4 hours, not only at startup.

### Also

- Releases publish themselves once every installer is built, so updates no longer go missing for Windows and macOS.
- Release builds no longer fail at random on Windows.

The full list is in the [CHANGELOG](https://github.com/behsse/yzo-browser/blob/main/CHANGELOG.md).
